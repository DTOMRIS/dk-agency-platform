# TASK-0425: Homepage "Sektordan ən son yeniliklər" now shows real news (B)

## Problem
The homepage news section (`components/NewsPreview.tsx`) rendered hardcoded
placeholder `NEWS_ITEMS`, so a section titled "sector news" showed stale/blog-like
content, and every card linked to the generic `/haberler` list instead of the
individual article — confusing (news label, blog-ish content).

## Fix
Rewrote `NewsPreview` to fetch real approved news client-side from the existing
public API `GET /api/news?limit=4&locale=<locale>` (returns `PublicNewsArticle[]`),
and link each card to its own article `/haberler/<slug>`. Design/layout, copy, and
the newsletter form are unchanged — only the data source and links changed. Null
cover images fall back to a DK gradient placeholder. Empty/error → cards simply
don't render (newsletter still shows); no fake data.

## Not touched
No new API (reused `/api/news`), no schema, no other components. Homepage stays a
client component (fetch on mount).

## Verification
- `tsc --noEmit` → 0 errors in NewsPreview.tsx
- `NEWS_ITEMS` no longer referenced; links now `/haberler/<slug>`
- Build deferred to CI (sandbox xlsx egress block)
