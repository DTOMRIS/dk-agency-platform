# TASK-0301

- Scope: News spine — persist (POST→PATCH) + display (content-first) + canonical fix. PR-A of the 3-PR plan from TASK-0300 audit.
- Reason: Manual news content was silently lost and the public page pushed readers to the external source. Root causes proven by the 10-agent audit (docs/reports/2026-06-11-news-360-audit-plan.md).
- Root causes fixed:
  1. `NewsEditorForm.submitDraft` always POSTed; second save of the same draft hit the UNIQUE slug constraint → generic 500 → freshly typed content silently lost.
  2. Form sent `newsType: 'foto'` but the API zod enum is `'photo'` → any save with "Foto xəbər" failed with 400.
  3. `mapPublicArticle.isManual` was derived from the `manual:` URL sentinel — a manual article with a real reference URL was treated as RSS and got the big red "Mənbədə tam xəbəri oxu" button.
  4. Detail-page canonical/hreflang/OG pointed to the nonexistent `/sektor-nebzi/` route → Google received a 404 canonical for every article.
- Affected:
  - `components/dashboard/NewsEditorForm.tsx`: savedId state; first save POSTs, every later save PATCHes `/api/news/admin/{id}`; slug input locked after first save; `foto`→`photo` (type, options, localStorage migration); error toast shows API detail.
  - `lib/repositories/newsRepository.ts`: `createNewsArticle` slug pre-check → typed `SLUG_EXISTS` error; `updateNewsArticleAdmin` accepts publishedAt/newsType/telegramSend/logoOverlay/externalUrl (externalUrl only when non-empty — NOT NULL UNIQUE); `mapPublicArticle.isManual` = `sourceId === null` (sentinel kept as fallback); `sourceId` added to public selects.
  - `app/api/news/admin/route.ts`: `SLUG_EXISTS` → 409 with human message instead of 500.
  - `app/api/news/admin/[id]/route.ts`: PATCH passes the five previously immutable fields.
  - `app/haberler/[slug]/page.tsx`: canonical/hreflang/OG `/sektor-nebzi/` → `/haberler/`; manual articles never show the big source button — real reference URL renders as a small "Mənbə: hostname" line; RSS behavior unchanged.
