## Funnel Stages
1. Registered (base: 100%)
2. Priorities set (priorities_set event)
3. Tool clicked within 24h (tool_recommended_clicked)
4. D7 return (any event >= 7 days after registration)

- `auth.role !== 'admin'` → redirect `/dashboard`
- Non-auth → redirect `/auth/login`
