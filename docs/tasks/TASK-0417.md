# TASK-0417 - News preview saves before opening

- Scope: Fix manual news preview opening a public URL before the article exists in the database.
- Root cause: `NewsEditorForm` preview button opened `/haberler/${draft.slug}?preview=true` directly. If the article had not been saved yet, or if the backend returned a different saved slug, the preview URL 404ed.
- Change: Preview now saves the article as `fetched` first, captures the API returned `id` and `slug`, updates editor state, then opens `/haberler/{savedSlug}?preview=true`.
- Verification target:
  - Preview from a new unsaved article should create a draft and open the saved slug.
  - Subsequent preview clicks should PATCH the same article instead of creating duplicates.
