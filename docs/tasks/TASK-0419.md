# TASK-0419: Onboarding dead-end fix + broken tool-link repair (P0)

## Description
New users picked their priorities, pressed Save — and the modal just closed
(`setOpen(false)` + `router.refresh()`), a dead-end at the highest-signal moment.
Investigation surfaced a deeper, already-live bug: `PRIORITY_TOOL_MAP` referenced
five tool slugs with no page route (`yemek-xerci`, `sikayet-analitigi` [route dir
is `sikayat-analizi`], `sikayet-cavablandirici`, `reklam-yazicisi`, `kst-yoxlayici`),
so `RecommendationWidget` and the `try_first_tool` nudge were already linking to 404s.

Scope = P0 (agreed with product):
1. **Fix the mapping first** — remove config-only/dead slugs; recover the working
   Complaint Analysis tool via a slug→route resolver (config stays untouched).
2. **Replace the dead-end** with an in-modal Step 2 personalized result screen.
3. **Gap priorities** (0 tools → `inventory`) show a "coming soon" + notify-me card
   (painted-door demand signal), instead of a silent empty result.

## Changes
- `lib/data/priorities.ts` — clean `PRIORITY_TOOL_MAP` (route-backed slugs only) +
  `SLUG_ROUTE_OVERRIDES` / `getToolRoute()` so `sikayet-analitigi` resolves to the
  `sikayat-analizi` route without editing the PROTECTED `marketing-tools-config.ts`.
- `components/onboarding/OnboardingModal.tsx` — `step`/`savedPriorities`/`notified`
  state; Save opens a result screen (recap chips, ≤3 tool cards, gap coming-soon card,
  "go to dashboard" CTA); flex-col `max-h-[90vh]` card with sticky footer (mobile);
  ESC/close on the result step finishes instead of re-arming the skip flag.
- `components/dashboard/RecommendationWidget.tsx` + `lib/nudge/rules.ts` — build tool
  URLs through `getToolRoute(slug)`, fixing the live 404 links.
- `lib/data/userEvents.ts` — add `onboarding_completed`, `gap_interest` events.
- `messages/{az,en,ru,tr}.json` — add `onboarding.result.*` keys (4 languages).

## Not touched
`lib/marketing-tools-config.ts` (PROTECTED, read-only via resolver), `middleware.ts`,
`lib/member-access.ts`, `lib/listingFieldConfig.ts`, `app/layout.tsx`, Header/Footer,
