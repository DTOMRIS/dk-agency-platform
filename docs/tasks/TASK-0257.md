# TASK-0257

- Scope: Fix 404 error on franchise blog details page due to non-safe slug in DB
- Reason: The blog post "Franchise Bedelleri: isim Hakkı, Royalti, Reklam — Neye, Niye Ödüyorsun?" (ID: 151) had a slug with spaces, colons, and a trailing question mark. Since `?` is the query separator, Next.js parsed the slug path parameter without it, resulting in a DB mismatch and 404.
- Affected:
  - Database: Updated the slug of blog post ID 151 to `franchise-bedelleri-isim-hakki-royalti-reklam-neye-niye-oduyorsun`.
  - `app/[locale]/blog/[slug]/page.tsx`: Added legacy redirects for the old broken/special-character slug to the clean canonical slug.
  - `components/dashboard/BlogEditorForm.tsx`: Enforced slugify on blur and during payload creation on save/publish to prevent non-URL-safe slugs in the future.
- DoD: Blog details page loads successfully for the franchise blog post, old broken URLs redirect to the canonical slug, and the editor automatically formats/sanitizes slugs.
