İlk versiyada 3 səssiz hesablama xətası tapıldı və düzəldildi (TS təmiz idi, build tutmazdı):
1. **Mənfəət vergisi gəlir üzərindən** hesablanırdı (`netProfit = ebitda − gəlir×20%`) → düzgün baza **mənfəət** (`max(0, ebitda)×20%`). Hər iki ssenari daxil 4 yerdə düzəldildi.
