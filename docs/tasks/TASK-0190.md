## P0-1: Françbuk 400 Fix
**Root cause:** Wizard `canContinue` only checked non-empty, but API zod schema requires min lengths (operationDescription: 20, others: 10). User could enter short text → wizard accepted → API rejected.
**Fix:**
- `fieldIsComplete()` now enforces min length: textarea ≥ 10 chars, text ≥ 2 chars
- FranchbookGenerator reads API error response body and displays specific validation messages (field name + zod issue)
- Generic "Françbuk yaradıla bilmədi" replaced with field-specific feedback

## P0-2: Quiz Option Contrast
**Root cause:** Score quiz option buttons had no explicit text color class → inherited muted body default.
**Fix:** Added `text-slate-700` (unselected) and `text-slate-900` (selected) — WCAG AA contrast on white bg.
**Scope:** FranchiseQuiz.tsx (shared) — fixes both ReadinessQuiz and BuyerChecklist.

## P0-3: lokasyon-analiz Dead Link
**Root cause:** Footer linked to `/marketinq/lokasyon-analiz` (no locale prefix → 404 on public routes). Page exists but is auth-gated.
**Fix:**
- Footer: removed link (auth-gated page shouldn't be in public footer)
- B2B panel: fixed href to `/dashboard/marketinq-ocagi/lokasyon-analiz` (correct internal route)
