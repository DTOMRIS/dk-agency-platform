# TASK-0558 — Sayt mesaj formu: WhatsApp-dan əvvəl, mesaj Telegram + mail + panelə çatır

Owner: Doğan. 2026-11-08 (Telegram screenshot): «Hep yazıyorsun ama mesaj bana gelmiyor — ya telegram ya mail olsun ama mesaj gelsin». Variant seçimi: «WhatsApp-dan əvvəl form».

## Problem
- Sahibin Telegram-ına yalnız «💬 WhatsApp düyməsinə basıldı (mesaj hələ göndərilməyib)» gəlirdi. Düymə ziyarətçinin telefonunda WhatsApp-ı açır, hazır mətn yazılır — amma ziyarətçi «Göndər»ə basmayanda heç nə çatmır. Bildiriş ancaq «klik» idi, mesaj deyil (TASK-0511/0529/0540).

## Specification
1. `POST /api/leads/message` (public-ok): ad (≥2), telefon (7–15 rəqəm), mesaj (2–2000). Honeypot `website` → səssiz 200. Limit: 5 mesaj / saat / IP (yalnız düzgün mesajlar sayılır).
2. Çatdırma: `kazan_leads` (business_type `diger`, intent `general`, mesaj `conversation_context`-də, qeyd «Sayt mesaj formu · səhifə») → `/dashboard/kazan-leads`; Telegram — ad, telefon, səhifə, mesajın tam mətni (480 simvolluq hissələr), «WhatsApp-da yaz» (ziyarətçinin nömrəsinə) + «Paneldə aç»; mail `ADMIN_EMAIL` (`siteMessageAdmin`). Bazaya yazılmayıbsa Telegram-da «⚠️ yalnız buradadır».
3. Ziyarətçiyə «çatdı» yalnız baza VƏ YA Telegram uğurlu olanda; ikisi də yoxdursa 503 → «göndərilmədi» + WhatsApp seçimi.
4. UI: `components/contact/MessageFormModal.tsx` PublicChrome-da bir dəfə. Saytdakı bütün `/api/leads/whatsapp` linklərini (capture click) və `openContact()` hadisəsini tutur (CTASections, ContactFunnel JS düymələri). Mesaj sahəsi düymənin hazır mətni ilə dolur. Altda «WhatsApp-da aç» — köhnə sayğaclı yönləndirmə (dəyişmədi). Dashboard/b2b-panel-də form yoxdur → WhatsApp əvvəlki kimi.
5. 4 dil (`messageForm`), mobil alt panel, Escape/fon kliki bağlayır, kontrast slate-700/900.
