# TASK-0561 — Sektor Nəbzi learns from the owner's decisions (repeats, taste, reject reasons)

Owner: Doğan. Approved 2026-11-25 («reddettiğim haberlere göre akıllandır» → 3-point plan → «telegram okey»).

## Problem (measured 2026-11-25, Neon `dk-agency`, read-only)
- Telegram delivery works (450 sent in 30 days, last 25.11 15:12 UTC). The owner rejected **43%** of 405 drafts.
- Patterns: (1) the same event again a day later from another feed/language — Hanoi «Bakı guşəsi» ×6, Şuşa turizm paytaxtı ×5,
  By Fateh ×4, 47 şadlıq sarayı ×4, Zanzibar ×3; (2) hotel-software vendor opinion/PR (LodgIQ, Cendyn, PerfectCheck, Pyramid,
  Tambourine) — technology category 64% rejected; (3) far-away hotel projects (Bitlis, Kocaeli, Şam, Şincan, Seul).
- Root cause of (1): `recentSignals()` excludes rejected articles, and `storyKey` compares source titles that arrive in
  different languages, so a rejected event re-enters as a new group.
- Relevance score does not separate approve/reject (86% of drafts scored 10–19).

## Specification
1. `lib/news/owner-feedback.ts` (new): once per synthesis run load (a) AZ titles sent to the owner in the last 7 days,
   (b) last 25 approved + 25 rejected titles (21 days) with reason. Never throws (no context = old behaviour).
2. Editor pass (`editorial.ts`) gets that block + rules 9 (same event as this week's titles → reject «təkrar xəbər»;
   a genuinely new fact is not a repeat) and 10 (clearly matches the owner's rejected kind and not the approved kind →
   reject; when unsure, keep — the owner decides). No extra AI call.
3. Deterministic backstop on the AZ draft title: 5-letter stems minus common HoReCa stems; repeat = 2 shared ≥2-digit
   numbers + 1 stem, or ≥3 stems covering ≥70%. Titles written in the same run are added too.
4. Telegram: after ❌, buttons «🔁 Təkrar / 📣 Reklam / PR / 🌍 Uzaq mövzu / 😐 Maraqsız» (`news:why:<code>:<id>`),
   optional; stored in `news_approval_delivery.reject_reason` (migration 0025, additive, nullable, CHECK on codes)
   and fed back to step 1.

## Replay on real data (30 days, 413 decided drafts)
Backstop alone: catches 34 of 177 rejected; 5 of 236 approved flagged — 4 of them are the same event the owner
approved twice (Qızıl Qaya, COP31 identical title, Türkiyə vergi, doluluq), 1 borderline. First version (no common-stem
list) flagged 23 approved → tuned. Re-worded repeats with ≤2 distinctive stems are left to the editor pass.
