# TASK-0308 - Email security (P0) + delivery tracking (P1)

- ID: `TASK-0308`
- Scope: Fix critical HTML injection in email templates, surface silent email failures, add delivery logging, connect homepage newsletter.

## P0 — Security
- **HTML injection fix**: All user-supplied values (leadName, ownerName, title, reason, message, phone, businessType, intent) now escaped via `escapeEmailHtml()` before insertion into email HTML. 5 template functions patched.
- **Silent catch removal**: 14 fire-and-forget `.catch(() => {})` patterns in email/AI send calls replaced with `console.error('[email] ...')` / `console.error('[ai] ...')` for observability. Non-email catch patterns (fetch/json parsing) left unchanged.

## P1 — Infrastructure
- **email_logs table**: New `email_logs` DB table (queued/sent/failed + messageId + errorMessage). Migration: `drizzle/0017_add_email_logs.sql`. `sendEmail()` now auto-logs every delivery attempt.
- **Homepage newsletter**: Footer newsletter form connected to `POST /api/newsletter/subscribe` with `source: 'homepage_newsletter'`. Previously only blog sidebar had this.
